Network architecture case study

PUP campuses
on Donx

An enterprise WAN that connects all 26 campuses of the Polytechnic University of the Philippines, from Sta. Mesa to Sablayan, through Donx Networks, a fictional regional ISP. It has a dual-homed BGP edge, an IPsec-protected overlay with two hubs, one OSPF area per campus, and a firewalled DMZ. Every device is fully configured and ready to build in Cisco Packet Tracer.

Architecture decisions

What was chosen, and what it costs

Each decision records the alternative that lost and the trade-off accepted. Where Packet Tracer limited a choice, it says so.

Campuses

26 campuses, five Donx service areas

The campus list follows PUP's official campuses page. Circuit tiers use the number of degree programs each campus lists as a stand-in for campus size: nine or more programs gets 1 Gbps, five to eight gets 500 Mbps, four or fewer gets 200 Mbps. Validate the tiers against enrollment data before ordering circuits.

The payoff: one policy, 26 campuses

Applied inbound on every lab and Wi-Fi gateway. The wildcard 0.255.0.255 ignores the campus octet and matches the role octet exactly.

ip access-list extended STUDENT-POLICY
 remark no ADMIN, MGMT or infrastructure, anywhere
 deny ip any 10.0.10.0 0.255.0.255
 deny ip any 10.0.99.0 0.255.0.255
 deny ip any 10.0.0.0  0.255.0.255
 permit ip any any

The WAN side follows the same idea. A campus's Donx circuit is 198.51.100.(4 × site ID)/30. For Taguig (site 12) that is 198.51.100.48/30, so the Donx side is .49 and PUP is .50. Each branch's tunnel is Tunneln on the hubs, where n is the site ID.

Public addressing uses only reserved documentation ranges (RFC 5737), and the lab Internet uses the RFC 2544 benchmarking range. The lab can never collide with real Internet prefixes.

Routing

Three routing domains, one clear boundary

PUP and Donx each run their own OSPF process and never exchange IGP routes. eBGP is the only place they meet. PUP's private routes exist only inside the encrypted overlay.

PUP · OSPF 10

Area 0 plus 25 campus areas

Sta. Mesa is area 0. Each branch is its own area, numbered by site ID. Both hubs are ABRs and summarize each campus to one /16 with area n range. A flapping lab switch in Ragay triggers SPF only inside area 45.

Donx · OSPF 1

Single-area backbone

Ten routers, loopbacks and /30 links in area 0, with MD5 on every adjacency. Customer /30s are passive networks. The IGW originates the default route. The PEs redistribute PUP's BGP prefixes, because Packet Tracer cannot run iBGP.

eBGP

Two edges, two POPs

PUP (AS 64510) peers with Donx at two separate POPs, Sta. Mesa and San Juan. Donx (AS 64500) peers with the simulated transit provider (AS 64496) and announces its own blocks plus PUP's /24.

BGP sessions and announcements

Packet Tracer workarounds, stated openly. Packet Tracer has no iBGP, so the Donx PEs redistribute BGP into OSPF. It has no neighbor default-originate, so PUP's edges use a static default toward their PE. Stub areas were considered and rejected: the DMZ prefix enters OSPF as an external route, and stub areas drop Type-5 LSAs.

Security

Nine layers, listed from the Internet inward

The order matters. Each layer assumes the one before it has failed.

Compliance context: the Student Information System holds personal data covered by the Data Privacy Act of 2012 (RA 10173). That is why it sits in the data centre VLAN, reachable only over the encrypted overlay and never published. Every device shows a login banner citing the Cybercrime Prevention Act (RA 10175).
